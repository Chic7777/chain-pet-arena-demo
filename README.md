# Chain Pet Arena

Chain Pet Arena 是一个可爱的 Web3 链游概念 Demo。

它模拟了一个 DApp 小游戏流程：连接模拟钱包、铸造宠物 NFT、训练宠物、进行战斗，并获得模拟 PET 代币奖励。

本项目用于学习和展示，不连接真实钱包，不调用真实区块链 API，不处理真实资产。

## 功能

- DApp 风格的模拟钱包连接弹窗
- 随机生成模拟钱包地址
- 铸造模拟宠物 NFT
- 训练宠物并提升经验
- 宠物战斗并获得模拟 PET 代币
- 显示模拟链上冒险日志

##安全说明
这是一个纯前端静态 Demo。
它不会：
- 连接真实 MetaMask 或其他真实钱包
- 请求真实签名
- 发送真实交易
- 部署或调用智能合约
- 保存私钥、助记词、API Key 或任何敏感信息
所有钱包地址、NFT、代币余额和链上日志都是模拟数据。

##项目目的
这个项目是 Hermes 7 日学习营的练习作品。
它的重点不是实现真实区块链功能，而是学习如何把一个模糊的 Web3 想法，逐步拆解成清晰需求，并做成一个可以运行、可以展示的小产品 Demo。
